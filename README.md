# 🌦️ Weather App

A modern and responsive Weather Application that provides real-time weather information for any city using a Weather API.  
This project is built using HTML, CSS, and JavaScript and is designed to help users quickly check weather conditions in a simple and user-friendly interface.

---

# 📌 Features

✅ Search weather by city name  
✅ Real-time temperature updates  
✅ Displays humidity and weather conditions  
✅ Dynamic weather icons  
✅ Responsive user interface  
✅ Simple and clean design  
✅ Fast and lightweight project

---

# 🛠️ Technologies Used

| Technology | Purpose |
|------------|---------|
| HTML | Structure of the application |
| CSS | Styling and responsiveness |
| JavaScript | Functionality and API handling |
| Weather API | Fetching real-time weather data |

# 🚀 How to Run the Project

## Method 1: Directly Open in Browser

1. Download or clone the repository
2. Open the project folder
3. Double-click on `index.html`

The Weather App will start in your browser.
